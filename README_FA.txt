WoSoCenter — اصلاح نمایش ناقص پنجره انتخاب بازیکن روی مک

این بسته تغییرات را روی نسخه فعلی فایل‌های سایت اعمال می‌کند، بدون اینکه فایل اصلی CSS یا HTML را بازنویسی و جایگزین کند.

تغییرات:
۱) افزودن height مشخص به پاپ‌آپ انتخاب بازیکن برای نمایشگرهای بیشتر از ۷۴۰ پیکسل
۲) تعیین flex-basis مناسب برای بدنه پنجره
۳) تغییر نسخه لینک CSS در lineup.html از 6.14.0 به 6.14.1 برای رفع مشکل کش

روش استفاده:
۱) پروژه wosocenter را روی کامپیوتر داشته باشید.
۲) فایل apply_fix.py را در پوشه اصلی پروژه، کنار lineup.css و lineup.html کپی کنید.
۳) از همان پوشه اجرا کنید:

    python3 apply_fix.py

۴) فقط دو فایل lineup.css و lineup.html را کامیت کنید:

    git add lineup.css lineup.html
    git commit -m "Fix Mac player popup layout"
    git push

نکته: اگر فقط از رابط وب GitHub استفاده می‌کنید، می‌توانید به‌جای اجرای اسکریپت، قواعد داخل فایل CSS_PATCH.txt را به انتهای lineup.css اضافه کنید و نسخه CSS را در خط ۸ lineup.html به 6.14.1 تغییر دهید.

این اصلاح بر اساس بررسی کد و اسکرین‌شات است و هنوز روی مک آزموده نشده است. در صورت عدم رفع، خطاهای Console و اندازه‌گیری computed style پنجره باید بررسی شوند.
