# WoSoCenter — اصلاح نام و پالت مارسی

این بسته فقط دو فایل داده را تغییر می‌دهد و نیازی به تغییر فایل‌های JavaScript، لوگو یا Cloudflare Worker نیست.

## نصب در GitHub

1. ابتدا از مخزن سایت با Code → Download ZIP نسخه پشتیبان بگیر.
2. فایل ZIP حاضر را استخراج کن.
3. به پوشه `data` مخزن `ByMehrdadZamani/wosocenter` در GitHub برو.
4. فایل‌های `teams.json` و `lineup-palettes.json` را با دو نسخه داخل پوشه `data` این بسته جایگزین کن و Commit changes را بزن.
5. بعد از موفق شدن GitHub Pages، شماتیک‌ساز را باز کن و یک بار بازخوانی کامل انجام بده.

## نتیجه

- «مارسی ۲» در لیست تیم‌ها، لوگوها و انتخاب تیم به «مارسی» تغییر می‌کند.
- پالت اختصاصی «مارسی» با آبی فیروزه‌ای، سرمه‌ای، طلایی و سفید اضافه می‌شود.
- هنگام انتخاب لوگوی مارسی برای «پترن پس‌زمینه»، همان پالت در «پالت پیشنهادی لوگوی پس‌زمینه» ظاهر می‌شود.
- هنگام انتخاب تیم مارسی برای شماتیک، پالت مارسی خودکار اعمال می‌شود.
- شناسه داخلی `mrsy-2` و مسیر تصویر `assets/teams/mrsy-2.webp` بدون تغییر می‌مانند تا پروژه‌های ذخیره‌شده قدیمی خراب نشوند.

توجه: این دو فایل صرفاً آماده نصب هستند. GitHub هنگام آماده‌سازی بسته دسترسی نوشتن مستقیم را نپذیرفت؛ برای اعمال تغییر باید آن‌ها را در مخزن جایگزین کنی.
