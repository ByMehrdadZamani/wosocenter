ساخت فایل‌های نصب نهایی ووسو سنتر

سه تغییر: تراز لوگوی هدر جدول، عکس جدید رزالیا دومینگز با اندازه استاندارد، و انتخاب کیفیت در دانلود هر صفحه یا تمام صفحات در همه ابزارها.

مهم: این فایل فقط بسته نصب نهایی را می‌سازد. خودش را در GitHub آپلود نکن. پس از زدن دکمه، یک ZIP جدید دانلود می‌شود که حاوی فایل‌های واقعی قابل نصب است.
  1. ابتدا در GitHub از سایت با Code → Download ZIP نسخه پشتیبان بگیر.
  2. روی دکمه بنفش زیر کلیک کن تا فایل‌های فعلی سایت خوانده و به‌روزرسانی شوند.
  3. پس از دریافت فایل WoSoCenter-Upgrade-v6.1-READY-TO-UPLOAD.zip، آن را استخراج کن.
  4. تمام محتویات ZIP جدید را با حفظ مسیر پوشه‌ها در مخزن GitHub جایگزین کن، سپس Commit changes بزن.
آماده دریافت فایل‌های فعلی سایت و تولید نسخه نصب‌شدنی

هیچ تغییری مستقیم در مخزن یا Worker انجام نمی‌شود. تصویر بازیکن فقط در فایل ZIP قرار می‌گیرد؛ تصاویر آپلودی خودت به سرور ارسال نمی‌شوند.
