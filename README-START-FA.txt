WoSoCenter — Upgrade v6.1
========================

تغییرات:
• تراز افقی باکس لوگوی هدر پوستر جدول با باکس های امتیاز تیم ها (x=34، عرض=58 پیکسل).
• جایگزینی تصویر رزالیا دومینگز (barca-38) در بانک، بندانگشتی، فهرست و کارت شماتیک.
• پرسیدن کیفیت (۲۱۶۰×۲۷۰۰ یا ۱۰۸۰×۱۳۵۰) قبل از دانلود تکی یا همه صفحات در کنداکتور، شماتیک، مصاحبه و جدول؛ PNG جداگانه.

توجه مهم:
این ZIP حاوی «سازنده نسخه نصب نهایی» است. برای تغییر کدهای اصلی سایت باید
ابتدا سازنده را در مرورگر اجرا کنی. خود فایل Generator را در GitHub آپلود نکن.

مراحل:
۱. در GitHub از مخزن wosocenter یک ZIP پشتیبان بگیر (Code → Download ZIP).
۲. این بسته را استخراج کن.
۳. فایل WoSoCenter-Upgrade-6.1-Generator.html را با مرورگر Chrome یا Edge باز کن.
۴. دکمه «ساخت و دانلود فایل نصب نهایی نسخه ۶.۱» را بزن.
۵. مرورگر فایل WoSoCenter-Upgrade-v6.1-READY-TO-UPLOAD.zip را دانلود می‌کند.
۶. فقط فایل ZIP تازه‌ساخته‌شده را استخراج کن. در آن ۱۶ فایل کامل وجود دارد.
۷. فایل‌های داخل آن را با حفظ مسیر پوشه‌ها در GitHub آپلود و جایگزین کن؛
   از جمله data/players.json و فایل های زیر assets/players/...
۸. Commit changes کن و بعد از سبز شدن Actions صفحات را با Ctrl+Shift+R بازخوانی کن.

برای «دانلود همه» ممکن است مرورگر اجازه دانلود چند فایل درخواست کند.
منبع API و تنظیمات Cloudflare تغییر نمی‌کنند.

اگر سازنده خطا داد، هیچ‌یک از فایل‌های موجود را پاک یا جایگزین نکن؛ متن خطا را بفرست.
