# WoSoCenter — کنداکتورساز فوتبال (قالب شماره ۱ / نسخه ۲)

وب‌سایت کاملاً ایستا و فارسی برای ساخت کنداکتور فوتبال؛ قابل انتشار روی **GitHub Pages** بدون سرور، پایگاه داده یا دامنه پولی.

خروجی تصویر: **PNG به اندازه ۱۰۸۰×۱۳۵۰ پیکسل**؛ ظرفیت: **۱ تا ۶ بازی**.

## امکانات نسخه ۲

- عنوان گرافیکی «برنامه» و پترن گلبرگی بازسازی‌شده از تصاویر جدید طراحی
- لایه مستطیلی با گوشه‌های گرد روی پترن و کادر ثابت مسابقات
- **Undo / Redo** با دکمه‌های بالای صفحه، میانبرهای `Ctrl+Z` و `Ctrl+Y`، و فهرست قابل کلیک **۵۰۰ مرحله اخیر** (به‌صورت محلی در مرورگر)
- انتخاب رنگ مستقل با **پنجره لمسی**، طیف رنگ، کد `#RRGGBB`، رنگ‌های پیشنهادی و انتخابگر رنگ دستگاه
- **۶ ترکیب رنگی آماده** برای کل طراحی، همراه با رنگ‌های جداگانه هر بازی
- حالت **روشن و تاریک** برای پنل سایت (خود تصویر کنداکتور با انتخاب رنگ‌های قالب تغییر می‌کند)
- پنجره **انتخاب تیم/پرچم/لوگوی لیگ/پترن** با امکان جست‌وجو و نمایش تصویر
- دو لوگوی نمونه و پرچم‌های پایه؛ مدیر مخزن می‌تواند هر تعداد مورد جدید به فایل‌های داده اضافه کند
- تغییر متن، رنگ و فونت نام لیگ، ساعت، تاریخ و آیدی کانال؛ رنگ مستقل هر لوگوی تیم و آیکون ساعت
- ذخیره محلی، ورود و خروج JSON، دانلود تصویر؛ نوشته‌های پایین سایت شامل ارتباط با سازنده `@ByMehrdad`
- واکنش‌گرا برای موبایل و کامپیوتر

**نکته:** ذخیره تغییرات و تاریخچه در مرورگر همان دستگاه انجام می‌شود. اگر کش/داده سایت پاک شود یا مرورگر عوض شود، ممکن است اطلاعات قبلی در دسترس نباشند. برای نگهداری بلندمدت از «دریافت تنظیمات JSON» استفاده کنید.

## انتشار نسخه دوم روی مخزن فعلی

مخزن پروژه: `https://github.com/ByMehrdadZamani/wosocenter`

سایت: `https://bymehrdadzamani.github.io/wosocenter/`

**برای به‌روزرسانی، مخزن جدید نسازید و GitHub Pages را دوباره تنظیم نکنید.**

روش پیشنهادی برای جایگزینی چند فایل موجود: **GitHub Desktop** (رایگان).

1. از https://desktop.github.com نرم‌افزار GitHub Desktop را نصب کنید و با حساب مالک مخزن وارد شوید.
2. `File` → `Clone repository` → مخزن `ByMehrdadZamani/wosocenter` را انتخاب کنید و `Clone` را بزنید.
3. فایل ZIP نسخه ۲ را Extract کنید. **محتویات** پوشه استخراج‌شده را در پوشه محلی مخزن کپی کنید و در صورت سؤال، فایل‌های هم‌نام را **Replace** کنید. مراقب باشید `index.html` در ریشه مخزن باشد. پوشه مخفی `.git` مخزن را حذف نکنید.
4. در GitHub Desktop از صفحه `Changes` تغییرات را ببینید، در قسمت Summary بنویسید `Update WoSoCenter v2` و روی `Commit to main` کلیک کنید.
5. روی `Push origin` کلیک کنید. GitHub Pages پس از انتشار تغییرات، همان آدرس قبلی را به‌روز می‌کند.
6. اگر نسخه قبلی را می‌بینید صفحه را با `Ctrl+Shift+R` تازه کنید یا یک‌بار در پنجره ناشناس باز کنید.

از رابط وب GitHub نیز می‌شود فایل‌های جدید را آپلود و فایل‌های متنی را ویرایش کرد؛ اما برای یک به‌روزرسانی چندفایلی، GitHub Desktop روش ساده‌تری برای جایگزینی فایل‌های هم‌نام است.

## افزودن تیم و لوگوی جدید — فقط مدیر سایت

این بخش نیاز به دسترسی ویرایش مخزن GitHub دارد. کاربران سایت فقط از فهرست موجود انتخاب می‌کنند و امکان آپلود تصویر ندارند.

### گام ۱ — لوگو را به پوشه تصاویر اضافه کنید

مثلاً فایل تصویر `barcelona.png` با بک‌گراند **شفاف** و کیفیت مناسب (پیشنهاد: PNG چهارگوش با حدود ۴۰۰×۴۰۰ پیکسل) را در این مسیر قرار دهید:

`assets/teams/barcelona.png`

برای انجام آن از خود GitHub، به پوشه `assets/teams` بروید، روی `Add file` → `Upload files` بزنید و فایل تصویر را آپلود کنید. بعد `Commit changes` را بزنید.

### گام ۲ — تیم را در بانک اطلاعاتی ثبت کنید

از GitHub فایل `data/teams.json` را باز کنید، روی آیکون مداد **Edit** بزنید و یک مورد به آرایه اضافه کنید.

نمونه فایل معتبر با سه تیم:

```json
[
  {"id":"servette","name":"سروت ژنو","image":"assets/teams/servette.png"},
  {"id":"nordsjaelland","name":"نورشلاند","image":"assets/teams/nordsjaelland.png"},
  {"id":"barcelona","name":"بارسلونا","image":"assets/teams/barcelona.png"}
]
```

هنگام اضافه کردن به انتهای آرایه، **بعد از مورد قبلی کاما بگذارید** و بعد از آخرین مورد کاما نگذارید. تمام نام فایل‌ها و مسیرها نسبت به حروف بزرگ و کوچک حساس‌اند. مقدار `id` باید انگلیسی، کوتاه و **یکتا** باشد.

تغییر را با `Commit changes` ذخیره کنید. پس از انتشار، تیم جدید در پنجره جست‌وجوی تیم‌ها نمایش داده می‌شود. هیچ تغییری در `app.js` لازم نیست.

### اضافه کردن پرچم یا لوگوی لیگ

- تصویر را به پوشه `assets/flags/` اضافه کنید.
- مورد جدید را به فایل `data/flags.json` اضافه کنید.
- برای لوگوی لیگ می‌توانید `"type":"league"` هم بگذارید تا در پنجره با عنوان «لوگوی لیگ» مشخص باشد.

مثال:

```json
{"id":"ucl","name":"لیگ قهرمانان اروپا","type":"league","image":"assets/flags/ucl.png"}
```

این مورد باید **داخل آرایه موجود** فایل `flags.json` قرار گیرد؛ نه به‌صورت یک فایل JSON جداگانه.

### افزودن پترن جدید

- تصویر پترن را در `assets/patterns/` قرار دهید.
- یک آیتم به `data/patterns.json` اضافه کنید:

```json
{"id":"pattern2","name":"پترن هندسی","image":"assets/patterns/pattern2.png","tileWidth":432,"tileHeight":430,"mode":"image"}
```

گزینه `mode` می‌تواند `image` (حفظ رنگ‌های فایل تصویر) یا `mask` (تغییر رنگ طرح شفاف با ابزار «رنگ پترن») باشد. برای `mask` از تصویری استفاده کنید که شکل‌های مورد نظر شفافیت درست دارند و زمینه ناخواسته ندارند. `tileWidth` و `tileHeight` ابعاد تکرار پترن برحسب پیکسل در خروجی ۱۰۸۰×۱۳۵۰ هستند.
