# WoSoCenter v3.6 — کنداکتورساز فوتبال


کنداکتورساز آنلاین فوتبال (GitHub Pages) با خروجی PNG در ابعاد ۱۰۸۰×۱۳۵۰، بانک لوگوی تیم، پرچم، الگوهای پس‌زمینه، پالت رنگی، تاریخچه و پنل ریسپانسیو.

## تغییرات نسخه ۳.۵

- **فونت پیش‌فرض کنداکتور:** آریو برای نوشته‌های تاریخ، روز هفته، نام لیگ، زمان، آیدی کانال و انتخابگر فونت سراسری در پروژه تازه و پس از «بازنشانی طرح» استفاده می‌شود. فونت خودِ رابط کاربری برای خوانایی تغییر نکرده است.
- **حذف فندوق:** این فونت از فهرست انتخاب و تعریف بارگذاری CSS حذف شده؛ اگر در پروژه ذخیره‌شده قبلاً فندوق انتخاب شده باشد، هنگام بارگذاری به آریو تبدیل می‌شود.
- **نمونه اولیه:** بازی بارسلونا و رئال مادرید حالا به صورت «لیگا اف اسپانیا» و با پرچم اسپانیا نمایش داده می‌شود. بانک پرچم‌ها تغییری نکرده است.
- **اطلاعات ذخیره‌شده کاربران:** پروژه‌های قبلی و تنظیمات شخصی کاربران بازنویسی نمی‌شوند؛ برای مشاهده پیش‌فرض جدید از «بازنشانی طرح» استفاده کنید (ابتدا از تنظیمات فعلی خروجی بگیرید).

## تغییرات نسخه ۳.۴

- **رنگ خودکار کادر تیم:** تا زمانی که رنگ همان کادر توسط کاربر تغییر نکرده، هر بار با انتخاب تیم جدید بر اساس رنگ پیشنهادی لوگوی جدید عوض می‌شود. تغییر دستی یا انتخاب پالت آماده، رنگ کادر را قفل می‌کند. این قفل برای هر کادر جداست.
- **اصلاح نام‌ها:** `liverpool-fc` → «لیورپول ۲»، `montpellier-fc-logo` → «مون پلیه»؛ حذف «سروت ژنو» (شناسه `servette`) از بانک؛ تنها تیم «سروت» (`srwt`) باقی مانده است.
- **موبایل:** نوار «بازی‌ها / تعداد مسابقات / افزودن بازی» هنگام اسکرول داخل تب مسابقات چسبنده است.
- **انتخابگر اختصاصی فونت:** پنجره قابل جست‌وجو با پیش‌نمایش «بارسلونا» به‌جای منوی پیش‌فرض سیستم؛ انتخاب مستقل برای هر متن حفظ شده است.
- **فونت‌های جدید:** استعداد، میخک، ساحل، شبنم، گندم، رویین، نقطه، آریو؛ فونت‌های قبلی هم حفظ شده‌اند.
- **همراه با اصلاحات نسخه ۳.۳:** رنگ پیشنهادی برندمحور تیم‌ها در `data/team-colors.json` و پوشانندگی ۶۰٪ کادر اصلی روی پترن.

## نصب آپدیت از طریق GitHub Web

۱. فایل ZIP آپدیت را Extract کنید.
۲. **محتویات** پوشه را در شاخه `main` و ریشه مخزن GitHub آپلود کنید؛ خود ZIP یا پوشه والد را آپلود نکنید.
۳. Commit changes کنید و نتیجه Pages را بررسی کنید.
۴. در صورت وجود، برای حذف فیزیکی تصویر قدیمی از مخزن، فایل `assets/teams/servette.png` را با گزینه Delete file حذف کنید؛ در فهرست انتخاب تیم پس از آپدیت دیگر نمایش داده نمی‌شود.
۵. صفحه سایت را با Ctrl+Shift+R تازه‌سازی کنید.

نکته: چون فایل `data/teams.json` در این آپدیت تغییر کرده، اگر پس از نسخه ۳.۲ تیم‌های جدیدی به بانک افزوده‌اید، پیش از جایگزینی از فایل فعلی نسخه پشتیبان بگیرید و ورودی‌های جدید را با نسخه آپدیت ادغام کنید. فایل‌های PNG سایر تیم‌ها در آپدیت دوباره آپلود نمی‌شوند.

## وضعیت فونت‌ها

هشت فونت جدید از CSS وب (WOFF2/TTF) با مجوز آزاد در `assets/fonts/fonts.css` به‌صورت **بارگذاری هنگام استفاده** معرفی شده‌اند؛ فایل باینری آن‌ها در بسته ZIP گنجانده نشده و از CDN دریافت می‌شود. به همین دلیل برای نخستین پیش‌نمایش یک فونت جدید به اینترنت دسترسی لازم است. در صورت عدم دسترسی به CDN، ممکن است فونت جایگزین دیده شود یا خروجی فونت منتخب آماده نشود. برای مسیر منابع و مجوزها `FONT-SOURCES.md` را ببینید. فونت‌های فعلی سایت همچنان در دسترس‌اند.
