# WoSoCenter — نسخه ۳.۲

کنداکتورساز فوتبال، مناسب GitHub Pages. رابط کاربری فارسی، پیش‌نمایش و خروجی PNG با ابعاد ۱۰۸۰×۱۳۵۰ پیکسل.

## تغییرات نسخه ۳.۲

- بانک ۸۳ تیم: ۸۱ نام یکتا از دو بسته ارسالی، همراه با دو تیم قدیمی.
- همه لوگوها به تصاویر PNG شفاف ۵۱۲×۵۱۲ با فضای خالی متوازن تبدیل شدند؛ هیچ لوگویی برای پرکردن قاب کشیده یا از اطراف بریده نمی‌شود.
- نام تیم‌ها از اسم فایل‌ها؛ خط تیره و آندرلاین به فاصله و اعداد به فارسی تبدیل شده‌اند.
- جست‌وجوی لحظه‌ای و شامل تمام بخش‌های نام (مثلاً «میلان» برای «آث میلان»). پشتیبانی از گونه‌های عربی/فارسی حروف و ارقام.
- پیشنهاد پیش‌فرض بارسلونا، رئال مادرید، بایرن مونیخ در صدر پنجره انتخاب تیم.
- هر تیم دارای رنگ پیشنهادی در `data/teams.json` است. رنگ هر کادر فقط هنگام اولین انتخاب تیم در آن کادر به‌طور خودکار تنظیم می‌شود؛ انتخاب‌های بعدی و رنگ دستی کاربر را تغییر نمی‌دهند.
- پیش‌نمایش پیش‌فرض کاربران جدید: بارسلونا و رئال مادرید. پروژه‌های ذخیره‌شده در مرورگر کاربران حفظ می‌شوند؛ برای دیدن پیش‌فرض جدید از «بازنشانی» استفاده کنید.
- تمام امکانات نسخه ۳.۱ شامل پالت‌ها، تاریخچه، پترن‌ها، رنگ و فونت‌ها حفظ شده‌اند.

## نصب از طریق وب GitHub

1. از فایل ZIP آپدیت، **محتویات** را Extract کنید (نه خود ZIP).
2. وارد مخزن `ByMehrdadZamani/wosocenter`، شاخه `main`، گزینه **Add file → Upload files** شوید.
3. محتویات استخراج‌شده را با مسیرهای پوشه‌ای موجود بارگذاری کنید؛ از ایجاد پوشه اضافی در ریشه خودداری کنید.
4. تغییرات را با **Commit changes** ذخیره کنید؛ بعد از انتشار GitHub Pages، صفحه سایت را بدون کش بارگذاری کنید.
5. اگر قبلاً به‌صورت دستی تیم‌هایی اضافه کرده‌اید، ابتدا یک نسخه از `data/teams.json` بگیرید تا موارد اختصاصی‌تان را با فایل جدید ادغام کنید.

## افزودن لوگوهای بیشتر

راهنمای کامل در [`ADD-LOGOS.md`](ADD-LOGOS.md) است. شکل هر آیتم:

```json
{
  "id": "barcelona",
  "name": "بارسلونا",
  "image": "assets/teams/barcelona.png",
  "color": "#1b3268"
}
```

- `id`: شناسه یکتا و ثابت، ترجیحاً انگلیسی.
- `name`: نام قابل جست‌وجو و نمایشی.
- `image`: مسیر نسبی فایل در پروژه.
- `color`: رنگ پیشنهادی شش‌رقمی HEX؛ در اولین انتخاب تیم برای کادر استفاده می‌شود.

**توجه:** دو فایل منبع، هر دو دارای «مارسی-2» بودند (SVG و WebP). برای جلوگیری از دو آیتم هم‌نام، فایل SVG حفظ شد. سایر فایل‌های نام‌متمایز، از جمله انواع «۲»، جداگانه ثبت شده‌اند.
