# کنداکتورساز فوتبال WoSoCenter — قالب ۱

نسخه اولیه قابل انتشار رایگان روی **GitHub Pages** با خروجی دقیق **1080×1350 پیکسل** و پشتیبانی از حداکثر **۶ بازی** در یک تصویر.

## امکانات

- یک مسابقه به شکل پیش‌فرض؛ دکمه **+** برای اضافه کردن و **×** برای حذف (حداقل یک و حداکثر شش مسابقه).
- انتخاب پرچم و لوگوی هر تیم **فقط از بانک فایل‌های مدیر سایت**؛ کاربر امکان آپلود تصویر ندارد.
- تغییر مستقل نام لیگ، ساعت، رنگ متن‌ها، فونت‌های هر بازی، رنگ پشت هر لوگو و رنگ آیکون ساعت.
- تغییر متن روز هفته و روز ماه با رنگ و فونت مستقل، بدون جابه‌جایی مبنای تراز متن.
- عنوان گرافیکی اصلی و لوگوی برند بر اساس تصاویر ارائه‌شده؛ رنگ دو بخش عنوان به‌طور مستقل تغییر می‌کند.
- تغییر نام/آیدی کانال در پایین طرح، رنگ متن، رنگ آیکون تلگرام و فونت نام کانال.
- تغییر رنگ پس‌زمینه، پترن، کادر اصلی و زمینه ردیف‌ها.
- انتخاب فونت کلی بدون تغییر دادن عنوان گرافیکی؛ همچنین انتخاب فونت جداگانه برای هر فیلد.
- ذخیره خودکار داده‌های فرم در مرورگر، خروجی و ورود فایل تنظیمات `JSON`، و دانلود `PNG` در اندازه اصلی.
- بدون بک‌اند و بدون وابستگی به سرویس اشتراکی؛ برای متن فونت‌های گوگل به اینترنت وابسته است و در صورت بارگذاری نشدن آن‌ها فونت جایگزین استفاده می‌شود.

## انتشار روی GitHub Pages — بدون نیاز به ابزار برنامه‌نویسی

۱. وارد [github.com](https://github.com) شو و به حساب خودت وارد شو.

۲. روی علامت **+** و سپس **New repository** بزن.

۳. نام مخزن را مثلاً `football-conductor` بنویس. گزینه **Public** را انتخاب و روی **Create repository** بزن.

۴. فایل ZIP را روی رایانه‌ات از حالت فشرده خارج کن. در صفحه مخزن، از **Add file > Upload files**، **محتویات پوشه استخراج‌شده** را آپلود کن؛ `index.html` باید مستقیماً در ریشه مخزن باشد، نه داخل پوشه اضافه و نه به صورت فایل ZIP. ساختار پوشه `assets` و `data` را حفظ کن.

۵. دکمه **Commit changes** را بزن.

۶. به **Settings > Pages** برو. در قسمت **Build and deployment**، گزینه **Deploy from a branch** را انتخاب کن؛ زیر Branch، مقدار **main** و **/(root)** را قرار بده و **Save** را بزن.

۷. آدرس سایت پس از انتشار معمولاً این‌طور است:

`https://USERNAME.github.io/football-conductor/`

به‌جای `USERNAME` نام کاربری GitHub خودت را قرار بده. اگر مخزن را نام دیگری دادی، در آدرس هم باید همان نام را بنویسی. انتشار اولیه ممکن است چند دقیقه طول بکشد.

راهنمای رسمی: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## ویرایش بانک تیم‌ها و لوگوها (ویژه مدیر)

**بانک لوگو:** `data/teams.json`

نمونه ردیف:

```json
{"id":"myteam","name":"نام تیم جدید","image":"assets/teams/myteam.png"}
```

برای افزودن تیم، ابتدا لوگوی آن را با زمینه شفاف (`PNG` یا `WebP`) داخل پوشه `assets/teams` قرار بده. سپس با رعایت ساختار JSON یک مورد جدید به آرایه فایل `data/teams.json` اضافه کن. `id` برای هر تیم باید یکتا و انگلیسی باشد. مسیرها نسبت به ریشه سایت نوشته می‌شوند. پس از ثبت تغییرات در GitHub و انتشار مجدد سایت، تیم در فهرست انتخاب ظاهر می‌شود.

**بانک پرچم‌ها:** `data/flags.json` و پوشه `assets/flags`. روش افزودن دقیقاً مشابه تیم‌ها است.

**نمونه‌های اولیه:** دو لوگوی ابتدایی از تصویر طراحی ارائه‌شده استخراج شده‌اند. برای بهترین کیفیت، فایل اصلی لوگوهای تیم‌ها را در آینده با نسخه‌های شفاف باکیفیت جایگزین کن.

> فایل‌های `teams.json` و `flags.json` «بانک اطلاعاتی فایل‌محور» هستند و پایگاه داده آنلاین با امکان مدیریت کاربران نیستند. فقط مدیر مخزن می‌تواند داده‌های مشترک را با ویرایش فایل‌های GitHub تغییر دهد.

## شخصی‌سازی قالب

- `index.html`: پنل و ظاهر ساختار فرم
- `styles.css`: طراحی سایت (نه خود تصویر کنداکتور)
- `app.js`: فیلدها، رنگ‌ها، چیدمان پیکسلی روی بوم، ذخیره و خروجی
- `assets/brand/`: پترن، ماسک رنگ‌پذیر عنوان و لوگوی برند برگرفته از تصاویر طراحی
- `assets/teams/`: تصویرهای تیم‌ها
- `assets/flags/`: پرچم‌ها
- `data/teams.json`, `data/flags.json`: بانک اطلاعاتی تیم‌ها و پرچم‌ها

**توجه:** فونت تصویر اصلی عنوان به‌صورت ماسک گرافیکی حفظ شده است، نه به‌صورت فایل فونت. فونت‌های دیگر متن‌ها از خانواده‌های عمومی و رایگان قابل انتخاب‌اند و ممکن است کاملاً با نمونه بصری برابر نباشند. مطابق خواسته، اندازه قلم‌های روی کنداکتور در پنل قابل تغییر نیست.

**توجه:** تنظیمات موقت کاربر در `localStorage` همان مرورگر ذخیره می‌شود. برای انتقال بین دستگاه‌ها از دکمه «ذخیره تنظیمات JSON» و «بازیابی تنظیمات» استفاده کن.
