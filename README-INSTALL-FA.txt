WoSoCenter v6.1 — راهنمای نصب

تغییرات:
۱. باکس لوگوی کانال در هدر پوستر جدول با ستون مربع امتیازها هم‌محور شد.
۲. تصویر رزالیا دومینگز (barca-38) در بانک بازیکنان با عکس آپلودی جدید جایگزین شد. ۴ تصویر بهینه برای لیست، بندانگشتی، تصویر اصلی و کارت استاندارد ۳۰۰×۳۱۰ داخل بسته قرار می‌گیرند.
۳. دکمه‌های دانلود در پنجره مدیریت صفحات جدول‌ساز، شماتیک‌ساز، مصاحبه‌ساز و کنداکتورساز پنجره انتخاب کیفیت ۲۱۶۰×۲۷۰۰ و ۱۰۸۰×۱۳۵۰ را نشان می‌دهند؛ دانلود همه صفحات، PNGهای جداگانه خواهد بود.

نصب:
۱. در GitHub به مخزن ByMehrdadZamani/wosocenter برو، Code > Download ZIP را برای پشتیبان بزن.
۲. فایل WoSoCenter-Upgrade-6.1-Generator.html را با Chrome یا Edge باز کن. به اینترنت نیاز دارد.
۳. روی «ساخت و دانلود فایل نصب نهایی نسخه ۶.۱» بزن.
۴. توجه: فایلی که تولید می‌شود WoSoCenter-Upgrade-v6.1-READY-TO-UPLOAD.zip است، نه فایل Generator. آن فایل ZIP را استخراج کن.
۵. محتویات ZIP نهایی را در مخزن جایگزین کن و ساختار پوشه‌ها را حفظ کن، مخصوصاً data/players.json و assets/players/...
۶. پس از سبز شدن GitHub Actions صفحه‌ها را با Ctrl+Shift+R تازه‌سازی کن.

این نسخه هیچ تغییری در Cloudflare Worker و API ندارد.
در دانلود چند صفحه، اندازه اعلامی نمونه‌ای از یک صفحه است و اندازه واقعی هر صفحه ممکن است متفاوت باشد. مرورگر ممکن است مجوز دانلود هم‌زمان چند فایل درخواست کند.

اگر خطای سازگاری فایل دیدی، فایل قدیمی را پاک نکن؛ متن خطا را ارسال کن.
