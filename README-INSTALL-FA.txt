WoSoCenter Site Upgrade v6.0
=============================

این نسخه ۴ مورد را اعمال می‌کند:
۱. جدول‌ساز: سرستون «تیم» دقیقاً بالای لوگو و مدیریت صفحات مشابه شماتیک‌ساز.
۲. شماتیک‌ساز: تنظیم مستقل قاب‌بندی چهره بازیکنان بانک برای هر کارت با کشیدن، زوم لمسی و پیش‌نمایش زنده، ذخیره در پروژه و خروجی PNG.
۳. کنداکتورساز، شماتیک‌ساز و مصاحبه‌ساز: پنجره دانلود با کیفیت‌های ۲۱۶۰×۲۷۰۰ و ۱۰۸۰×۱۳۵۰ و حجم واقعی فایل.
۴. جدول‌ساز: پنجره دانلود دوکیفیتی خود را از قبل دارد و آن را حفظ می‌کند.

روش استفاده:
۱. از مخزن GitHub با Code > Download ZIP نسخه پشتیبان بگیر.
۲. فایل «WoSoCenter-Update-Builder-v6.html» را در مرورگر کامپیوتر باز کن.
۳. روی «ساخت بسته نصب» بزن. ابزار فقط فایل‌های عمومی مخزن را می‌خواند و چیزی روی GitHub تغییر نمی‌دهد.
۴. فایل «WoSoCenter-Site-Upgrade-v6.zip» را استخراج کن.
۵. تمام فایل‌های خروجی را در ریشه مخزن (همان پوشه index.html) با نسخه موجود جایگزین کن.
۶. Commit changes، سبز شدن GitHub Actions و سپس رفرش کامل را انجام بده.

پوشه و فایل‌های تیم‌ها، فونت‌ها، عکس‌ها، صفحه اصلی و Worker نیازی به تغییر ندارند.
داده‌های شخصی مرورگر یا کلیدهای API در این بسته ذخیره نمی‌شوند.

راهنمای تست:
- جدول‌ساز: ستون تیم و گالری صفحات، حرکت و دانلود تکی.
- شماتیک‌ساز: باز کردن کارت، انتخاب بازیکن، تنظیم چهره، تأیید قاب‌بندی و سپس ✓ ذخیره کارت؛ زوم و پن در PNG هم اعمال می‌شوند.
- هر سه ابزار دیگر: دکمه دریافت PNG، مشاهده دو کیفیت و حجم واقعی، دانلود تکی هر کیفیت.
- دانلود همه صفحات همچنان به صورت فایل‌های جداگانه است.

پیش‌نیاز: مرورگر در زمان ساخت بسته به اینترنت و GitHub دسترسی داشته باشد.
در صورت دریافت پیام عدم سازگاری، دانلود بسته متوقف می‌شود تا نسخه نادرست روی سایت نصب نشود.
