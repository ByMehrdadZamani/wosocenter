روش نصب:
  1. از مخزن GitHub پشتیبان بگیرید: Code -> Download ZIP.
  2. فایل ZIP آپدیت را در دستگاه استخراج کنید.
  3. فقط 8 فایل فهرست‌شده را از داخل ZIP در ریشه مخزن آپلود کنید.
  4. در صفحه GitHub روی Commit changes بزنید.
  5. منتظر بمانید GitHub Actions -> pages build and deployment موفق شود.
  6. در مرورگر Ctrl+Shift+R (و در موبایل تب/کش را تازه) کنید.
  7. admin.html را باز کنید؛ رمز Cloudflare قبلی همچنان معتبر است.
  8. در lineup.html روی یک کارت بزنید و گزینه «+ ساخت بازیکن جدید» را تست کنید.

نکات مهم:
  * برای هماهنگی نام/لوگوهای هدرهای ابزار، افزونه woso-site-ui.js توسط
    woso-analytics.js که همین حالا در هر چهار صفحه بارگذاری می‌شود فراخوانی می‌گردد.
    بنابراین نیازی به تغییر کامل HTML یا JS قدیمی ابزارها نیست. <title> هر تب بعد از
    بارگذاری به صورت زنده تغییر می‌کند؛ کد ثابت <title> در منبع HTML قدیمی ابزار
    تا زمانی که آن فایل‌ها مستقیماً ویرایش نشوند همان نام سابق را دارد.
  * فایل اصلی lineup.js، عکس‌ها، داده بازیکنان و فایل‌های Worker دست‌نخورده‌اند.
  * عکس بازیکن دلخواه به Cloudflare، GitHub یا دیتابیس عمومی ارسال نمی‌شود.
    در sessionStorage دستگاه و حافظه همان تب نگهداری می‌شود؛ با بستن نشست/تب حذف
    می‌شود. اگر ذخیره‌سازی موقت مرورگر محدود باشد، ممکن است بعد از Refresh از دست برود.
    پوستر PNG دانلودشده همچنان قابل استفاده است. قبل از بستن تب خروجی بگیرید.
  * پروژه‌های قدیمی حاوی شناسه بازیکن دلخواه پس از پایان نشست عکس را نخواهند داشت.
  * آمار فعلی Worker و دیتابیس D1 تغییری نکرده و Secrets قابل‌دسترسی یا موردنیاز نیستند.
  * روز آماری Worker با Europe/Berlin محاسبه می‌شود؛ تبدیل تاریخ به شمسی
    فقط در نمایش داشبورد انجام می‌شود و داده دیتابیس تغییر نمی‌کند.
  * دو کیفیت دانلود و سایر ابزارهای سایت باید پس از نصب یک بار بررسی شوند.
  * در نصب نسخه بعدی از جایگزینی این فایل‌ها با نسخه‌های قدیمی خودداری شود.
