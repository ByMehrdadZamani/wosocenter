WoSoCenter — Rosalia Dominguez / Patri standard — v6.2

رفع مشکل بزرگ بودن چهره رزالیا دومینگز (barca-38) در کارت شماتیک‌ساز.
این بسته فقط ۳ تصویر را جایگزین می‌کند و کدهای سایت، اطلاعات بازیکنان، Worker و پروژه‌های ذخیره‌شده را تغییر نمی‌دهد.

بر اساس بانک رسمی سایت:
- پاتری (barca-24): اندازه اسمی چهره 102.1 × 108.9، تاج سر در y=64.
- رزالیا در نسخه قبلی: 118 × 128 (بزرگ‌تر از پاتری).
- رزالیا در نسخه جدید: حدود 101 × 109، تاج سر در y=64، کادر شفاف 300 × 310.

نصب:
۱) ابتدا از مخزن GitHub پشتیبان بگیر (Code > Download ZIP).
۲) فایل ZIP حاضر را از حالت فشرده خارج کن.
۳) هر سه فایل داخل پوشه assets را با حفظ مسیر دقیق در مخزن جایگزین کن:
  assets/players/lineup-calibrated/barca-38-rosalia-v2.png
  assets/players/picker/barca-38-rosalia-picker-v2.webp
  assets/players/thumbs/barca-38-rosalia-thumb-v2.webp
۴) Commit changes بزن و بعد از انتشار موفق GitHub Pages صفحه شماتیک‌ساز را با بازخوانی کامل باز کن.
۵) اگر قبلاً برای کارت رزالیا زوم دستی تنظیم کردی، از «تنظیم چهره بازیکن در کارت» گزینه بازگشت به پیش‌فرض/اندازه پیش‌فرض را بزن؛ مقدار زوم ذخیره‌شده می‌تواند تصویر جدید را همچنان بزرگ کند.

نکته: فایل‌ها با همان نام و مسیر فعلی ساخته شده‌اند تا نیاز به تغییر data/players.json یا lineup.js نباشد. ممکن است کش GitHub Pages یا مرورگر برای مدت کوتاهی نسخه تصویری پیشین را نمایش دهد. هیچ داده‌ای را از حافظه مرورگرت پاک نکن.
