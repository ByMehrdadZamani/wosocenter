# جدول‌ساز WoSoCenter — نسخه ۵.۲ (اصلاح انتخاب فونت)

این بسته برای ارتقای نسخه ۵.۱ جدول‌ساز است و فقط ظاهر و عملکرد پنجره انتخاب فونت را تغییر می‌دهد.

## تغییرات

- فهرست فونت‌های پنجره انتخاب فونت از شبکه دو‌ستونه به لیست عمودی تک‌ستونه تبدیل شد.
- نام هر فونت و عبارت «بارسلونا» با همان فونت در یک ردیف نمایش داده می‌شود.
- فونت انتخاب‌شده با کادر بنفش و علامت ✓ مشخص می‌شود.
- ایراد قدیمی تفسیر نام فونت در ویژگی `font-family` پیش‌نمایش اصلاح شد.
- فونت‌ها از فایل‌های موجود در `assets/fonts` خود سایت استفاده می‌کنند؛ هیچ فونتی به بسته اضافه نشده است.
- به‌دلیل پشتیبانی صرفاً لاتین، گزینه Georgia برای حروف فارسی به فونت جایگزین مرورگر متکی است؛ بقیه پیش‌نمایش‌ها از فونت‌های فارسی موجود در سایت استفاده می‌کنند.

## روش نصب در GitHub

۱. پیش از تغییر، از مخزن GitHub با Code → Download ZIP یک پشتیبان تهیه کن.
۲. ZIP نسخه ۵.۲ را استخراج کن.
۳. **فقط سه فایل** `standings.html`، `standings.css` و `standings.js` را در ریشه مخزن `ByMehrdadZamani/wosocenter` جایگزین کن و Commit changes بزن.
۴. بعد از موفق شدن GitHub Actions، آدرس `https://bymehrdadzamani.github.io/wosocenter/standings.html` را با Ctrl + Shift + R بازخوانی کن.
۵. در تب هدر یا جدول، روی انتخاب فونت بزن و فهرست جدید را بررسی کن.

**توجه:** نیازی به تغییر Worker، بانک لوگو، فایل‌های پترن، تصاویر، index.html یا سایر ابزارهای سایت نیست. تنظیمات ذخیره‌شده و منطق جدول‌ساز تغییر نکرده‌اند.

## کنترل کیفیت

- Node.js: بررسی نحوی کد JavaScript با موفقیت انجام شد.
- تست مرورگر در دسکتاپ و موبایل: ۲۱ گزینه در فهرست تک‌ستونه، نمونه «بارسلونا»، حالت فونت انتخاب‌شده، انتخاب و بسته‌شدن پنجره بدون خطای JavaScript بررسی شدند.
- در محیط تست، فایل‌های فونت سایت بارگذاری نشدند؛ نمایش دقیق شکل هر فونت باید پس از آپلود نسخه جدید به GitHub Pages کنترل شود.
