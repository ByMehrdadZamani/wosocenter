# جدول‌ساز WoSoCenter — اصلاحات نسخه ۵٫۱

## نصب آسان روی GitHub Pages

این بسته برای ارتقای **نسخه ۵** جدول‌ساز است. در آن **فقط سه فایل کد جدول‌ساز** تغییر کرده‌اند:

- `standings.html`
- `standings.css`
- `standings.js`

۱. در GitHub روی **Code → Download ZIP** بزن و پشتیبان کل مخزن را ذخیره کن. از پروژه جدول‌ساز هم در صورت نیاز، در تب **تغییرات → خروجی تنظیمات JSON** پشتیبان بگیر.
۲. این بسته را از حالت ZIP خارج کن.
۳. این سه فایل را در **ریشه مخزن** `ByMehrdadZamani/wosocenter` جایگزین فایل‌های هم‌نام نسخه ۵ کن و **Commit changes** را بزن.
۴. پس از سبزشدن GitHub Actions، صفحه `https://bymehrdadzamani.github.io/wosocenter/standings.html` را باز کن و یک بار با **Ctrl + Shift + R** بازخوانی کامل انجام بده.

لازم نیست فایل‌های تصویر، `data/teams.json`، سایر ابزارهای سایت یا Cloudflare Worker را دوباره تغییر بدهی. دو تصویر نسخه ۵ به نام‌های `assets/standings/ewa-pajor-default.webp` و `assets/standings/wosocenter-wordmark.webp` باید از نصب قبلی موجود باشند. تصویر حلقه ستاره‌ای سابق دیگر در کد استفاده نمی‌شود؛ می‌تواند بدون مشکل در پوشه قدیمی باقی بماند.

## تغییرات این نسخه

۱. متن تصویری **WoSoCenter** در هدر، در ارتفاع مرکز لوگوی کانال تراز شد. جابه‌جایی دلخواهِ کاربر در تنظیمات هدر همچنان قابل اعمال است.
۲. حلقه ستاره‌ای لیگ قهرمانان از اطراف امتیازهای رتبه‌های ۱ تا ۳ و **تاج** از امتیاز تیم اول کاملاً حذف شدند؛ گزینه تنظیم رنگ حلقه نیز از پنل حذف شد.
۳. ورود اولیه بدون داده ذخیره‌شده به‌جای جدول خالی، **پیش‌نمایش کامل ۱۶ تیمی نمونه** را نشان می‌دهد. داده نمونه برگرفته از اطلاعات تاریخی **۱۱ نوامبر ۲۰۲۶** است، آنلاین محسوب نمی‌شود و داخل صفحه با برچسب «پیش‌نمایش نمونه» مشخص می‌شود. با «ساخت خودکار جدول»، این نمونه جای خود را به داده آنلاین می‌دهد. داده آنلاین قبلاً ذخیره‌شده در مرورگر به جای نمونه نمایش داده خواهد شد.
۴. جای آیدی کانال و آیکون تلگرام به‌صورت یک گروه دقیقاً در مرکز عرض پوستر و مرکز فاصله بین ردیف آخر جدول تا لبه پایین پوستر تنظیم شد.
۵. باکس امتیاز تیم اول **همیشه طلایی** می‌ماند؛ پالت و پترن فقط شید رنگ طلایی آن را تغییر می‌دهند. رنگ‌های اختصاصی غیرطلایی ذخیره‌شده قدیمی نیز روی باکس رتبه اول اعمال نمی‌شوند. کنترل رنگ اختصاصی باکس رتبه اول با توضیح «طلایی ثابت» جایگزین شد.
۶. پس از دریافت اطلاعات، بخش «دریافت جدول آنلاین» پیامی مانند «۱۶ تیم دریافت شد. آخرین دریافت اطلاعات: امروز ۲۱:۱۴» به وقت محلی مرورگر نشان می‌دهد. زمان نمایش‌داده‌شده **زمان دریافت توسط جدول‌ساز است**، نه الزاماً زمان آخرین مسابقه لیگ.

بقیه امکانات نسخه ۵، شامل تصویر پس‌زمینه، تنظیم تصویر، پالت‌ها، تاریخچه، مدیریت صفحات و دانلود PNG در دو کیفیت حفظ شده‌اند.

## تست‌های انجام‌شده

- آزمون نحوی JavaScript با Node: موفق.
- آزمون اجرای مرورگری محلی با داده آزمایشی: پیش‌نمایش ۱۶ تیم، تغییر پالت، رنگ طلایی رتبه اول، نمایش زمان دریافت و آماده‌سازی PNG بدون خطای JavaScript.
- آزمون روی GitHub Pages واقعی بعد از نصب باید انجام شود.

**فایل `patch.py` و ابزارهای تست جزو بسته نصب نیستند.**
