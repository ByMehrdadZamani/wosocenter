# جدول‌ساز WoSoCenter — نسخه ۴ (طرح جدید بدون ستون صعود/سقوط)

## قبل از نصب
از مخزن GitHub با **Code → Download ZIP** نسخه پشتیبان بگیر. این بسته برای مخزن `ByMehrdadZamani/wosocenter` تهیه شده و **هیچ تغییری در Cloudflare Worker لازم ندارد**.

## فایل‌ها و مقصد دقیق آنها در GitHub

| فایل داخل بسته | محل قرارگیری در مخزن | کارکرد |
|---|---|---|
| `standings.html` | ریشه مخزن | پنل جدید + پنجره‌ها |
| `standings.css` | ریشه مخزن | ظاهر هماهنگ با شماتیک‌ساز |
| `standings.js` | ریشه مخزن | موتور رسم و مدیریت ابزار |
| `data/teams.json` | پوشه `data` | بانک ۸۳ تیمی؛ ۸۲ مورد قبلی + ایبار |
| `assets/teams/eybar.webp` | پوشه `assets/teams` | لوگوی شفاف ایبار (مورداستفاده در بانک) |
| `assets/teams/eybar.png` | پوشه `assets/teams` | نسخه PNG لوگوی ایبار |

**نکته:** سه فایل `standings.*` را در ریشه آپلود کن. فایل `teams.json` را **داخل پوشه `data`** جایگزین کن. دو تصویر ایبار را **داخل `assets/teams`** قرار بده. فایل‌ها نباید اشتباهاً همگی در ریشه مخزن آپلود شوند.

### نصب با وب‌سایت GitHub
۱. وارد `https://github.com/ByMehrdadZamani/wosocenter` شو.
۲. در ریشه مخزن: `Add file → Upload files` و سه فایل اصلی را آپلود/جایگزین کن، سپس Commit.
۳. وارد پوشه `data` شو؛ از `Add file → Upload files` فایل `teams.json` را آپلود و جایگزین کن؛ Commit.
۴. وارد پوشه `assets/teams` شو؛ دو فایل `eybar.webp` و `eybar.png` را آپلود کن؛ Commit.
۵. پس از موفقیت `pages build and deployment` صفحه `https://bymehrdadzamani.github.io/wosocenter/standings.html` را باز کن. اگر نسخه قدیمی را دیدی `Ctrl+Shift+R` بزن.
۶. برای آغاز، دکمه «دریافت اطلاعات آنلاین» را بزن و بعد PNG دانلود کن.

## تغییرات نسخه ۴
- طرح گرافیکی طبق نمونه جدید؛ جدول عریض‌تر و بالاتر، ۱۶ ردیف، بدون هر نوع فلش، نشانه تغییر رتبه، مرجع هفته قبل یا مقایسه صعود/سقوط. تنها رنگ باکس امتیاز دو تیم آخر (محدوده سقوط) مطابق نمونه حفظ شده است.
- رفع ترتیب علامت مثبت/منفی تفاضل گل با ترسیم مجزای علامت در سمت چپ عدد فارسی.
- لیگ: پنجره اختصاصی فهرست بانک لوگوهای لیگ؛ لیگا اف فعال و باقی به‌زودی. انتخاب فصل در پنل حذف شده است.
- نام فارسی ۱۶ تیم، ایبار با لوگوی جدید از بانک تیم‌ها، بادالونا طبق خواسته جدید با لوگوی «لوانته بادالونا» در بانک فعلی.
- هدر: نام لیگ و هفته پویا و امکان متن/شماره هفته دستی؛ نام کانال قابل ویرایش، تنظیم فونت/رنگ/اندازه، انتخاب لوگوی ووسو سنتر یا بارسلونا از بانک مصاحبه‌ساز. آیدی کانال در پایین تصویر قابل ویرایش است.
- انتخابگر اختصاصی رنگ شبیه شماتیک‌ساز (HEX، طیف رنگ، ناحیه شدت/روشنایی، رنگ‌های آماده).
- تنظیم عکس: پنجره برش با گرید، کشیدن آزاد، اسکرول موس برای زوم، لمس چندانگشتی، زوم و جابه‌جایی وسیع‌تر.
- انتخاب پترن دو تب، گالری تصاویر کاربر و طرح آماده؛ تصویر آپلودی فقط در مرورگر ذخیره می‌شود و بعد از اولین استفاده وارد گالری می‌شود.
- مدیریت صفحات با پیش‌نمایش واقعی هر صفحه، باز کردن، تغییر نام، تکثیر، حذف، افزودن و دانلود فایل‌های PNG مجزا (غیر ZIP).
- تاریخچه، واگرد، بازانجام، ذخیره خودکار و خروجی ۲۱۶۰×۲۷۰۰ حفظ شده‌اند.

## محدودیت‌های مشخص و آگاهانه
- خروجی فعلی `/api/standings` از Worker و API Ninjas **شماره هفته مستقل برنمی‌گرداند**. ابتدا عدد هفته از بیشترین تعداد بازی انجام‌شده در جدول **برآورد** می‌شود؛ اگر تیمی بازی عقب‌افتاده داشته باشد یا تقویم نامتوازن باشد، ممکن است با شماره رسمی هفته متفاوت شود. در تب هدر می‌توانی آن را اصلاح کنی. اگر Worker در آینده فیلد دقیق `week`/`matchweek`/`round` عددی برگرداند، همان عدد استفاده می‌شود.
- **تصویر خام اوا پایور** هنوز دریافت نشده است. تصویر نمونه ارسالی حاوی متن و جدول است، بنابراین به‌عنوان پس‌زمینه پیش‌فرض قرار داده نشده تا جدول دوبار تکرار نشود. عکس خام بازیکن را از تب «تصویر بک‌گراند» آپلود کن.
- فایل فونت مستقل **Celandine** در بانک فونت فعلی سایت نیست؛ برای نوشته پیش‌فرض WoSoCenter از فایل وردمارک خود سایت (`assets/brand/title-purple-hq.webp`) با رنگ/اندازه قابل تنظیم استفاده می‌شود. اگر متن نام کانال را تغییر بدهی، تا وقتی فونت Celandine به شکل مجاز در سایت نصب نشده باشد، جایگزین سیستمی نمایش داده خواهد شد. **هیچ فایل فونتی در این بسته وجود ندارد.**
- تصویر رزالیا دومینگز برای شماتیک‌ساز هنوز ارسال نشده؛ بنابراین هیچ فایلی در شماتیک‌ساز تغییر نمی‌کند.
- داده‌ها و عکس‌های کاربر در حافظه همین مرورگر ذخیره می‌شوند. فایل پروژه JSON شامل فایل عکس نیست.
- دانلود «تمام صفحات» به‌صورت فایل‌های PNG مستقل انجام می‌شود. در صورت درخواست مرورگر، دسترسی دانلود چند فایل را تأیید کن.
- ورودی `data/teams.json` از بانک GitHub با **۸۲ عضو** در زمان ساخت بسته تهیه شده؛ اگر پس از آن در بانک لوگوهای سایتت تغییر تازه‌ای انجام داده‌ای، قبل از جایگزینی، نسخه جدیدتر را مقایسه کن تا تغییرات تازه از بین نروند.

## بررسی انجام‌شده
- JavaScript از `node --check` عبور کرد.
- در Chromium با داده تستی ۱۶ تیم، پنل، دریافت داده شبیه‌سازی‌شده، لوگوی ایبار، پنجره لوگوی هدر، کالرپیکر، ایجاد و پیش‌نمایش صفحات، ذخیره عکس، زوم اسکرول و دانلود PNG آزمایش شدند. خطای اجرای JavaScript مشاهده نشد.
- اتصال زنده مرورگر به سایت GitHub Pages در محیط تست میسر نبود؛ پس پس از نصب، بررسی نهایی در سایت لازم است.
- ۴۰۴ تصاویر در تست ناشی از عدم دسترسی به سایر assetهای مخزن در محیط آفلاین بوده، نه غیبت آن‌ها در GitHub اصلی.

اگر بعد از نصب مشکلی رخ داد، سه فایل اصلی و `data/teams.json` را از ZIP پشتیبان برگردان؛ فایل جدید ایبار به‌تنهایی آسیبی به سایت نمی‌زند.
