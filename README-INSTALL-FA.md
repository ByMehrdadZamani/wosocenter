# WoSoCenter — جدول‌ساز کامل (نسخه ۳)

## نصب روی GitHub Pages

این بسته تنها **سه فایل اصلی سایت** را تغییر می‌دهد و به Worker فعلی API Ninjas دست نمی‌زند.

۱. یک نسخه پشتیبان از فایل‌های فعلی `standings.html`، `standings.css` و `standings.js` داخل مخزن `ByMehrdadZamani/wosocenter` بگیر.
۲. فایل ZIP را استخراج کن. در ریشه همان مخزن GitHub گزینه **Add file → Upload files** را بزن.
۳. **فقط این سه فایل** را به ریشه مخزن انتقال بده و جایگزین هم‌نام‌ها کن:
   - `standings.html`
   - `standings.css`
   - `standings.js`
۴. روی **Commit changes** بزن و بعد از موفقیت Pages deployment لینک زیر را باز کن:
   https://bymehrdadzamani.github.io/wosocenter/standings.html
۵. صفحه را با Ctrl+F5 / Hard Refresh باز کن تا نسخه کش‌شده قدیمی بارگیری نشود.
۶. روی **دریافت اطلاعات آنلاین** کلیک کن. باید ۱۶ تیم فصل ۲۰۲۶/۲۷ را ببینی. سپس می‌توانی همه تنظیمات و **دریافت PNG** را آزمایش کنی.

**نیازی به تغییر فایل `index.html` یا Workers و Secrets نیست.** دکمه جدول‌ساز از قبل در صفحه اصلی سایت موجود است.

## امکانات

- استفاده از همان هدر، تم، پنل و سبک بصری مشترک کنداکتورساز و شماتیک‌ساز؛ ۶ تب: دریافت اطلاعات، تصویر بک‌گراند، هدر، جدول، پترن، تغییرات
- دریافت اطلاعات معتبر از Worker فعلی (بدون کلید API در کد سایت)
- نمایش ۱۶ تیم بر اساس رتبه API، ارقام فارسی، ۱۰ ستون آمار، باکس طلایی صدرنشین، آبی رتبه ۲ و ۳، قرمز دو تیم آخر، آیکون تاج و ستاره‌های تزیینی
- نام فارسی تیم‌ها طبق `teams.txt` شما، تطبیق با `data/teams.json` و `assets/teams/` بانک سایت
- تنظیم هدر سمت راست و متن WoSoCenter سمت چپ، فونت و اندازه و رنگ و موقعیت هر دو به صورت مستقل
- تنظیم عکس پس زمینه: آپلود، کشیدن عکس با موس/لمس، جابه‌جایی، زوم و استفاده مجدد در لیست عکس‌ها؛ ذخیره فایل‌ها فقط در IndexedDB مرورگر
- Fade با رنگ، میزان پوشش، درصد شروع عکس و نرمش گرادیان؛ پترن‌های موجود بانک `data/patterns.json`
- رنگ و فونت جدول، پالت پیشنهادی Liga F، پالت WoSoCenter و پالت‌های آماده فعلی سایت؛ انتخاب رنگ مشابه ابزارهای قبلی
- تنظیم اختصاصی هر تیم: متن، لوگو (از بانک یا آپلود)، فونت، اندازه و رنگ نام، رنگ اعداد، رنگ عدد و باکس امتیاز، تغییر رتبه به صورت اختیاری
- لیست تغییرات، واگرد/بازانجام، مدیریت صفحات مستقل، ذخیره خودکار، خروجی و ورود پروژه JSON (برای تنظیمات)
- پیش‌نمایش ۱۰۸۰×۱۳۵۰ و **PNG نهایی با رسم مستقیم ۲۱۶۰×۲۷۰۰**

## چند نکته مهم

- API Ninjas در خروجی فعلی **رتبه هفته قبل** را برنمی‌گرداند. بنابراین وقتی مرجع قبلی وجود ندارد، علامت **؟** نمایش داده می‌شود، نه فلش یا خطی که ممکن است نادرست باشد. برای مقایسه رتبه‌ها، در پایان یک هفته، دکمه «ثبت جدول فعلی به‌عنوان هفته قبل» را بزن؛ پس از برگزاری هفته جدید، دوباره «دریافت اطلاعات آنلاین» کن. یا JSON جدول هفته قبل را وارد کن. همچنین در تنظیمات هر تیم می‌توان علامت را دستی انتخاب کرد.
- بانک فعلی `data/teams.json` برای **۱۴ تیم** لوگوی دقیق دارد. برای **ایبار و FC بادالونا** ورودی مستقل ندارد. برای این دو فعلاً مخفف تیم نمایش داده می‌شود؛ لوگوی درست آن‌ها را در تنظیمات اختصاصی تیم آپلود کن. **لوگوی لوانته بادالونا به‌جای FC بادالونا استفاده نشده است.**
- تصویر نمونه‌ای که فرستادی شامل متن‌ها و خود جدول است و **عکس خام بازیکن ندارد**. به همین علت عکس بازیکن به‌طور پیش‌فرض در این بسته نیست؛ برای داشتن تصویر مشابه، عکس خام بازیکن را از تب «تصویر بک‌گراند» آپلود کن. تا آن زمان پوستر دارای پس‌زمینه آبی/گرادیانی است.
- ذخیره تصاویر فقط روی مرورگر/دستگاه تو با IndexedDB انجام می‌شود و در مخزن یا API آپلود نمی‌شود. پاک شدن داده‌های سایت در مرورگر باعث حذف تصاویر ذخیره‌شده می‌شود. فایل پروژه JSON شامل تنظیمات و شناسه عکس‌های همان مرورگر است، **خود عکس‌ها را داخل JSON قرار نمی‌دهد**.
- رتبه ۱ در خروجی «صدرنشین فعلی» است، نه لزوماً قهرمان قطعی فصل.
- اگر یک آیکون، لوگو یا پترن نمایش داده نشد، مسیر فایل را در بانک سایت بررسی کن. نسخه فعلی تا حد امکان بدون آن تصویر هم خروجی می‌دهد.
- این نسخه از لحاظ HTML / ساختار فایل و Syntax جاوااسکریپت بررسی شده است، اما به دلیل محدودیت مرورگر محیط ساخت، **آزمایش تعامل آن روی GitHub Pages لازم است**.
