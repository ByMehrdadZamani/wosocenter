# جدول‌ساز ووسو | نسخه ۵ — راهنمای نصب

این بسته تنها **بخش جدول‌ساز** WoSoCenter را به‌روزرسانی می‌کند؛ از فایل‌های مشترک موجود در مخزن (فونت‌ها، لوگوها، `styles.css`، بانک تیم‌ها و پالت‌ها) استفاده می‌کند.

## قبل از شروع

1. از مخزن `ByMehrdadZamani/wosocenter` یک نسخه پشتیبان با **Code → Download ZIP** بگیر.
2. اگر در حال کار روی یک پروژه جدول‌ساز هستی، می‌توانی از تب **تغییرات → خروجی تنظیمات JSON** هم فایل پروژه را ذخیره کنی؛ عکس‌هایی که فقط در مرورگر ذخیره شده‌اند جزو این JSON یا پشتیبان مخزن نیستند.
3. این بسته را روی فایل‌های نسخه ۴ نصب کن؛ لوگوی ایبار و `data/teams.json` باید قبلاً طبق بسته نسخه ۴ نصب شده باشند. اگر آن مرحله را نصب نکرده‌ای، اول نسخه ۴ را کامل نصب کن.

## محتویات ZIP

```text
standings.html
standings.css
standings.js
assets/
  standings/
    ewa-pajor-default.webp
    wosocenter-wordmark.webp
    uefa-stars.webp
README-INSTALL-FA.md
```

## نصب روی GitHub

**بخش ۱ — جایگزین‌کردن کدها**

- به ریشه مخزن `https://github.com/ByMehrdadZamani/wosocenter` برو.
- روی **Add file → Upload files** بزن.
- سه فایل `standings.html`، `standings.css` و `standings.js` را آپلود و جایگزین کن. برای بروزرسانی یک فایل موجود، اگر GitHub از جایگزینی مستقیم در همان صفحه جلوگیری کرد، وارد خود فایل شو، **Edit** را بزن و متن تازه را به جای نسخه قبلی قرار بده.

**بخش ۲ — اضافه‌کردن تصاویر جدید**

- وارد پوشه `assets` شو. اگر زیرپوشه `standings` وجود ندارد، با **Add file → Create new file** و نام `standings/.gitkeep` آن را بساز و Commit کن. سپس پوشه `standings` قابل مشاهده است.
- در مسیر `assets/standings/`، این سه تصویر را آپلود کن: `ewa-pajor-default.webp`، `wosocenter-wordmark.webp`، `uefa-stars.webp`.
- لازم نیست فایل‌های اصلی JPG یا PNG چندمگابایتی را آپلود کنی؛ فایل‌های WebP داخل بسته نسخه کم‌حجم و مناسب وب هستند.

**بخش ۳ — بررسی انتشار**

- وارد **Actions** شو و مطمئن شو آخرین `pages build and deployment` سبز شده.
- صفحه `https://bymehrdadzamani.github.io/wosocenter/standings.html` را باز کن؛ برای دیدن نسخه جدید، صفحه را با **Ctrl+Shift+R** (یا در موبایل با نوسازی صفحه) تازه کن.

## چه چیزی تغییر کرده؟

- تصویر پیش‌فرض بازیکن در پس‌زمینه جدول (حدود **۷۰ کیلوبایت**) و تنظیمات Fade پیش‌فرض **۱۰٪ / ۸۰٪ / ۱۰۰٪**.
- عبارت تصویری ثابت **WoSoCenter** در سمت چپ هدر؛ رنگ، اندازه و موقعیت آن قابل تغییر است. خود نوشته قابل جایگزینی با متن دیگر نیست.
- عنوان خودکار از «نام لیگ + هفته» با قالب «جدول هفته دهم لیگا اف» وقتی هفته ۱۰ باشد. گزینه متن دلخواه و اصلاح دستی هفته همچنان در تب هدر باقی است.
- گردی **۱۵ پیکسل** برای گوشه‌های لوگوی کانال در پوستر.
- طرح ستاره‌ای فایل ارسالی روی امتیازهای سه تیم بالای جدول؛ به‌صورت پیش‌فرض سفید و با پالت قابل تغییر.
- کنترل **ورود عدد + ↺ بازنشانی** کنار اسلایدرها.
- پنجره انتخاب فونت با پیش‌نمایش و بارگذاری فونت‌ها در زمان بازکردن پنجره.
- **۱۰ پالت اصلی** در صفحه و «نمایش همه پالت‌ها» در پنجره جداگانه؛ بعد از اعمال پالت، صفحه به شکل نرم به پیش‌نمایش می‌رود. در تب پترن، پالت پیشنهادی طرح انتخابی نمایش داده می‌شود؛ برای عکس شخصی نمایش داده نمی‌شود.
- پنجره انتخاب لیگ به‌صورت **لیست عمودی** و باکس طلایی مخصوص ساخت خودکار جدول.
- آیکون ساعت، تب **تغییرات** را با هدایت نرم به تنظیمات باز می‌کند.
- فوتر صفحه با لینک `@ByMehrdad` مطابق ابزارهای دیگر سایت.
- پنجره **انتخاب کیفیت دانلود**: `2160 × 2700` یا `1080 × 1350` پیکسل؛ حجم واقعی PNGها قبل از انتخاب محاسبه می‌شود. مدیریت صفحات و دانلود تک‌تک صفحات همچنان باقی است.
- تنظیمات ذخیره‌شده نسخه ۴، تصاویر آپلودشده کاربر و اطلاعات Worker حفظ می‌شوند.

## دو نکته مهم

1. **شماره هفته در API فعلی مستقل گزارش نمی‌شود.** جدول‌ساز ابتدا فیلد هفته را در داده Worker بررسی می‌کند؛ اگر وجود نداشت، بیشترین تعداد بازی انجام‌شده تیم‌ها را *برآورد شماره هفته* می‌گیرد. برای اطمینان می‌توانی در تب **هدر** هفته را دستی اصلاح کنی.
2. **پروژه‌های قبلی مرورگر:** جدول‌ساز تنظیمات و تصویر آپلودشده قدیمی‌ات را خودکار حفظ می‌کند. برای انتخاب عکس پیش‌فرض جدید، در تب **پترن → تغییر → تصویر دلخواه → تصویر پیش‌فرض** بزن؛ یا پس از گرفتن خروجی پروژه، پروژه جدید بساز.

## تست قبل از استفاده جدی

ابتدا دریافت اطلاعات، انتخاب پالت، پیش‌نمایش، پنجره دانلود ۲ کیفیت، تغییر نام تیم و مدیریت صفحات را در مرورگرت امتحان کن. **این نسخه با داده آزمایشی و مرورگر محلی آزمایش شده اما روی GitHub Pages واقعی شخص تو هنوز نصب/تست نشده است.**

**لازم نیست Cloudflare Worker، کلید API، `index.html` یا سایر ابزارهای سایت را تغییر بدهی.**
